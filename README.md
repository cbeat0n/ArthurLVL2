### Arthur MVP
#Arthur is an end to end software using Python and CSS/JS in order to trade USDJPY, extended for other currencies past MVP. It takes OANDA candlestick data and does homebrewed data analysis in order to calculate buying and selling pressures and do matrix algebra on them to find signal. It is modular and agnostic, although OANDA will likely be the committed trading platform.
# I worked on this project from July to September, cleaning up jagged and dirty data doing data analysis to create the buying and selling pressures from scratch. In this repository, files to name include transform_*.py. The entire ETL pipeline works with OANDA in order to make this finance style transformation happen. I had to take a break for family reasons for about a year in order to fix a few things and came back. 
# From 11/3 to 11/10 I worked on the robustness of the repository. Information can be found in the docs folder. All across the repository, guardrails and exceptions were added, and code was rearranged to protect against any potential failures.
